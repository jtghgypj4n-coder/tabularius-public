This review covers the vendor plug-ins asked for in r20-09 and the additional prefixes/names already recognized by `docs/plugin-compatibility.md`. It uses public vendor documentation only. A function's name or result is not inferred from a prefix, marketing summary, sample created for tests, or behavior of a different product version.

## Existing coverage

The four requested notes (`plugins-installed-and-360works-email`, `plugins-baseelements-pack`, `r17e-14-mbs-leftovers`, and `r17f-05-plugin-owner-stubs`) are not present under `docs/` or `notes/` in this worktree. On `main`, `docs/plugin-compatibility.md` already reports 435 MBS functions, 128 BaseElements functions, 32 named BaseElements functions returning `?`, and 12 named calls across 360Works Email/DataGuard/one `MBS` alias. It already recognizes the `TrFile_`, `TrText_`, `TrURL_`, `TrSerial_`, `Dlg_`, `SMTPit_`, `DataGuard_`, `PCQB_`, `PCOL_`, `EvaluateGroovy`, and `RegisterGroovy` prefixes. `packages/fmp12/src/calc.ts` has 10 named 360Works Email functions plus `DataGuard_PostDelete`; it does not map Troi external owner/index pairs. `packages/calc/src/functions.ts` implements the missing-plug-in result as `?` for those known names/prefixes.

The generated compatibility page now links to this survey and lists the reviewed vendor products. The Troi owner code and owner/index function numbers for the new named calls have not been established from vendor documentation, so unknown encoded calls remain `?`.

### Troi Text function pages and classifications

- `TrText_GetLine ( switches ; lineNumber ; theText )`: pure text. The [function page](https://www.troi.com/online-help/text-plugin/textp6/) specifies the line delimiter, retained return character, optional `-ReturnAtEnd`, blank-line result, and empty result for out-of-range/invalid numbers. Implemented as a built-in compatibility function.
- `TrText_XML ( switches ; nodeSpec ; XMLData )`: pure text/XML by input/output class. Its [function page](https://www.troi.com/online-help/text-plugin/textp15/) names `-GetNode` and `-GetAttributes`; it does not supply enough complete result/edge-case examples for a compatible implementation in this item.
- `TrText_Version ( switches )`: OS/install/registration/version state and a possible UI action; its [function page](https://www.troi.com/online-help/text-plugin/textp9001/) documents install path, registration, and flash-dialog switches. It remains `?`.
- `ANDText`, `XORText`, `NOTText`: the [product page](https://www.troi.com/products/textplugin/) describes line-set relationships, but not ordering, duplicate handling, or all edge cases. These remain `?`.
- The same product page describes clipboard retrieval, unique-line/word, sorting, XML, and spell-check features. Where it does not publish a function name, this audit does not create one.
