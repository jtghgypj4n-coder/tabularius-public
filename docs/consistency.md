# Cross-module consistency decisions

Sources checked 2026-10-15. Regression probes are in
`packages/store/test/consistency.test.ts` (renamed from the audit file).

| Audit item | Decision and evidence |
|---|---|
| A4-12: nonzero numbers displayed as zero | Fixed: only round when fixed decimals are requested. [Claris number formatting](https://help.claris.com/en/pro-help/content/formats-number-fields.html) ties decimal rounding to the specified fixed decimal count. Preserve the existing plain-decimal display, including percentages and separators. |
| A4-13: maximum characters | Fixed to use the same Unicode code-point counter as calculation Length and SQL CHAR_LENGTH. [Claris Length](https://help.claris.com/en/pro-help/content/length.html) defines a character count, but does not specify surrogate pairs or grapheme clusters. Emoji parity with FileMaker itself is **unverified**; this change implements the requested internal Length-unit consistency without changing Length's existing semantics. Combining marks remain separate characters in that unit. | <!-- known-difference: SQL and calculations ;; Whether FileMaker counts an emoji (a surrogate pair) or a combining mark as one character is unverified; Length counts Unicode code points ;; Length of text with emoji or combining marks may differ from FileMaker ;; A FileMaker run of Length on emoji and combining-mark text -->
| A4-06: passkey second factor | Fixed with documented application code 9000; Claris calculation code 1212 is preserved. See [error codes](error-codes.md#application-extensions). |
| A4-01, A4-02, A4-03: missing objects and repetitions | Fixed to 106, 108, and 111 by the documented Claris meanings. See [error codes](error-codes.md#cross-module-corrections) for the distinction between meaning and observed endpoint behavior. |
| A4-07: SQL lower | Fixed: SQL LOWER uses Unicode lowercase, matching calculation Lower for É → é. [Claris SQL string functions](https://help.claris.com/en/sql-reference/content/functions-that-return-character-strings.html) and [calculation Lower](https://help.claris.com/en/pro-help/content/lower.html) both specify lowercasing letters, without an ASCII-only restriction. This does not establish every locale-sensitive case conversion. |
| A4-04: invalid audit retention | Fixed: 960 (invalid parameter), instead of a date-field validation error. |
| A4-05: SQL refusal | Retained 8310 and documented its existing SQL/OData uses in the shared catalog; FileMaker also returns this code in practice despite its absence from Claris's published list. |

Neither establishes that SQL `É = e` should match a find.
