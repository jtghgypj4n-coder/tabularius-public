# TABULARIUS_TRACE_SQL

Enables SQL statement tracing to stderr.

| Setting | Value |
| --- | --- |
| Default | Off |
| Accepted values | Any nonempty value except 0 enables tracing |
| Restart needed | Yes; restart the server after changing its environment. |
