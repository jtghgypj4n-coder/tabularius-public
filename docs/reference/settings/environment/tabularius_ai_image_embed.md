# TABULARIUS_AI_IMAGE_EMBED

`voyage` or `jina`, the service that embeds images for Perform Semantic Find by image (its key is `TABULARIUS_AI_IMAGE_EMBED_KEY`).

| Setting | Value |
| --- | --- |
| Default | Image embedding off |
| Accepted values | voyage or jina |
| Restart needed | Yes for a running server. |
