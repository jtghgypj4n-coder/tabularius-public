# TABULARIUS_HTTP_PORT

The port that answers the certificate challenge and redirects to https (80 by default).

| Setting | Value |
| --- | --- |
| Default | 80 |
| Accepted values | Port number from 0 to 65535, digits only |
| Restart needed | Yes for a running server. |
