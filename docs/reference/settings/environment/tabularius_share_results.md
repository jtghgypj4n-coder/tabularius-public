# TABULARIUS_SHARE_RESULTS

Controls in-memory sharing of query results when enabled by the server.

| Setting | Value |
| --- | --- |
| Default | Enabled when result sharing is configured and the file is not encrypted |
| Accepted values | 0 disables sharing |
| Restart needed | Yes for a running server. |
