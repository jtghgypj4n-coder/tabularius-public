# TABULARIUS_SQL_PORT

The port for the PostgreSQL-compatible SQL connection.

| Setting | Value |
| --- | --- |
| Default | SQL listener off |
| Accepted values | Port number from 0 to 65535, digits only |
| Restart needed | Yes for a running server. |
