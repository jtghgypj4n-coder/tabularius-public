# TABULARIUS_HOST

The address to listen on (`127.0.0.1` by default; `0.0.0.0` with `--https name`).

| Setting | Value |
| --- | --- |
| Default | 127.0.0.1 (0.0.0.0 with automatic HTTPS) |
| Accepted values | IP address or hostname |
| Restart needed | Yes for a running server. |
