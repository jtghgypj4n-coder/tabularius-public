# TABULARIUS_OIDC_TRUST_EMAIL

`1`, `true` or `yes` to accept the provider's email address as the account name.

| Setting | Value |
| --- | --- |
| Default | Off |
| Accepted values | 1, true or yes to turn on; 0, false, no or empty for off; "on", "off" and anything else stop `serve` |
| Restart needed | Yes for a running server. |
