# If

If is a script flow script step. This page describes how the offline Tabularius engine handles it.

- **Support:** works
- **Registry ID:** 68

## What the engine does

Evaluates the condition and runs only the matching branch.
## Options

Supply a Boolean calculation; Else If and Else choose other branches.

## Privileges

Permission to run the script; access to any named record, field, layout or file is checked at use.

## Error codes

Known codes from the engine and the [script error-code reference](../../error-codes.md): `0`. Other failures can arise from calculations or targets used by the step.

## Offline script example

Use a synthetic local solution with an empty `Examples` table and a text field named `Name`. The example uses no mail, network or plug-ins.

```script
Set Variable [ $result ; Value: "before" ]
If [ True ]
  Set Variable [ $result ; Value: "after" ]
End If
Exit Script [ Text Result: $result ]
```

**Expected end state:** The script result is `after`; no record changes.
