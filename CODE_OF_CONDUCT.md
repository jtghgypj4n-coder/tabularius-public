# Code of conduct

Tabularius is for people who run and maintain FileMaker solutions, many of whom are not programmers and some of whom are in a hurry because a business depends on a file. Everyone who writes in an issue, a pull request, a discussion or any other space for this project is asked to keep it a place where they can ask a plain question and get a plain answer.

## What we expect

- **Be kind about questions.** Nobody was born knowing what a privilege set or a pull request is. Answer the question that was asked.
- **Disagree with ideas, not people.** Say what you think is wrong and why. Do not guess at someone's motives.
- **Respect privacy.** Never post another person's data, a customer's records, a password or a token, yours or anyone's. If you see one posted, tell a maintainer (below) so it can be removed, and consider it exposed.
- **No harassment.** No insults, slurs, threats, sexual attention nobody asked for, or following someone around the project to bother them.
- **Stay on the work.** Issues and pull requests are for the project. Promotion that is not about the project is not welcome.

## What happens when it is not met

A maintainer may edit or remove a comment, close or lock a thread, and ask someone to stop. Repeated or serious harm can mean being blocked from the project's spaces. We will say what we did and why, to the person concerned, unless saying so would put someone at risk. Maintainers hold themselves to the same expectations.

## Reporting a problem

Tell a maintainer privately, using GitHub's private reporting on the repository (**Security**, then **Report a vulnerability**): say in the first line that it is a conduct report, not a vulnerability, and it will be handled as one. No email address is published for this. Do not use a public issue or comment for a conduct report. We will read what you send, keep it between the people who have to act on it, and answer you.

This code applies in the project's own spaces and when someone represents the project in public. It is written in plain words on purpose; it is not a legal contract.
