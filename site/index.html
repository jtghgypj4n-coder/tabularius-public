How it works

Keep the solution you built. Give it a modern home.

Tabularius opens the .fmp12 files you already have and runs them, layouts, scripts, calculations and all, on a server you control. Nothing to rebuild and no new platform to learn.

1
Drop in your .fmp12

Tables, layouts, scripts, accounts and records are read straight from the file. Your original is never changed.

2
Host it yourself

On a server you already own. One command, or Docker.

3
Work anywhere, with AI

Any browser, any device, and assistants that respect every account's privileges.

Convert

Drop in a .fmp12 and it is hosted.

Tabularius reads the whole file and tells you, in plain English, what won’t work yet and what works differently, along with the built-in replacement.

  • One program hosts the file; no other server software
  • Calculations run live: unstored, stored, auto-enter and validation
  • A report of what works, what differs and what to do
Web client

Your layouts, in any browser.

Themes, portals, tab and slide controls, popovers and conditional formatting, drawn the way the original layout draws them. Edit layouts right in the browser.

  • Browse, Find, Layout and Preview modes
  • Form, list and table view
  • Record locking and live updates in every window

Scripts

Scripts that run, and rewind.

Scripts run on the server from buttons, triggers, the Data API and AI. Record a run on a scratch copy, then step backwards and forwards through every variable and field change.

  • Debugger with breakpoints and a Data Viewer
  • Linter that catches loops that can't end
  • Some BaseElements and MBS functions run as built-in code
AI

AI that knows your whole solution.

A built-in MCP server lets Claude and other assistants explore your schema, find and edit records, and check what a change would break. Every call runs as the signed-in account.

  • Find with AI, and dashboards from a sentence
  • "Why did this script fail?" with the exact step
  • Switch AI off per file; pseudonymize personal data
Hosting

Your server. Your data. Your rules.

Run it where you choose. Accounts and privilege sets come with the file, and you can add passkeys, SSO, daily online backups and an access review.

  • One-command install, or Docker
  • Data API and OData for your integrations
  • Nothing leaves your server unless you allow it
